# 00 — Introduction

**Experience AI en une phrase :** transformer une intention en **parcours** personnalisé.

Une intention (envie, passion, objectif) + un contexte (avec qui, quand, où) → un parcours cohérent de moments, éditable, que l'utilisateur vit. Le voyage n'est qu'un format ; une soirée, un EVG, un festival, un séminaire en sont d'autres.

## Comment lire cette documentation
Les documents sont numérotés dans l'**ordre de conception** : chaque couche justifie la suivante. On part du *pourquoi* (philosophie), on descend jusqu'au *comment* (modèle, capacités), et la technique n'arrive qu'en dernier — comme conséquence, pas comme point de départ.

## Les trois niveaux
- **Founder Book** — la vision, l'origine, l'intuition. Le *pourquoi*.
- **Documentation Produit** (ce dossier) — *comment fonctionne le produit*.
- **Documentation Technique** (`docs/architecture/`) — *comment fonctionne le code*.

## Le principe qui gouverne tout
Un bon produit n'est pas une accumulation de fonctionnalités : c'est un ensemble cohérent de décisions qui tiennent des années. Cette documentation **est** ce cadre de décision.
