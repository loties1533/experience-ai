# ADR-0003 — Les agents sont des modules, pas des microservices

**Date :** 2026-07-23 · **Statut :** Accepté

## Contexte
La vision évoque à terme 20-30 agents IA spécialisés. Risque de sur-ingénierie pour un développeur solo.

## Décision
Les agents sont des **modules d'un seul service**, pas des microservices. On en crée **peu**, chacun justifié par une fonctionnalité concrète.

## Alternatives envisagées
- Un microservice par agent.
- Un seul gros prompt monolithique qui fait tout.

## Pourquoi ce choix
- La complexité opérationnelle de N microservices est ingérable en solo.
- **Un agent = un outil au service d'une capacité**, jamais l'inverse.

## Conséquences
- Le 1er vrai agent = **Modification** (la modif chirurgicale).
- Les autres agents ne sont ajoutés qu'en réponse à un besoin observé.
