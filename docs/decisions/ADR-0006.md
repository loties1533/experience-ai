# ADR-0006 — Le repo est la source de vérité (docs as code)

**Date :** 2026-07-23 · **Statut :** Accepté

## Contexte
La documentation s'était éparpillée en une dizaine de Google Docs, sans versioning ni source unique (risque de sprawl `Version_finale_v2_bis`).

## Décision
La **documentation produit vit dans le dépôt Git** (markdown, `docs/`). Google Drive est rétrogradé au **partage / présentation / note temporaire** — plus jamais une référence.

## Alternatives envisagées
- Google Drive comme référence du projet.
- Un wiki externe (Notion, Confluence).

## Pourquoi ce choix
- Git **versionne nativement** → une seule vérité, historique propre, pas de doublons.
- C'est du **texte** → survit à tout changement de stack.
- Éditable / fusionnable / supprimable proprement (ce que le connecteur Drive ne permet pas).

## Conséquences
- Structure `docs/` numérotée (00-13) + `docs/decisions/` (ADR).
- Les brouillons Drive existants seront supprimés une fois portés.
