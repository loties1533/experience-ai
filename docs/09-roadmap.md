# 09 — Roadmap

> Construire par couches ; chaque étape apporte de la valeur. La maturité produit suit **A → B → C**.

## Maturité (pourquoi l'utilisateur revient)
- **A** — on ouvre quand on a une envie à concrétiser *(MVP)*.
- **B** — inspiration / découverte → augmente la **fréquence**.
- **C** — mémoire intelligente → **fidélisation** long terme.

## Phases produit
1. **Cadre & fondations** (cette documentation) — *en cours*.
2. **Modèle de données** (traduction du [`06`](06-modele-conceptuel.md)).
3. **Cœur** : parcours = état adressable + **agent Modification**.
4. **Entrée orientée envie** + validation du brief.
5. **Mémoire simple** (préférences).
6. **Maîtrise des coûts** (cache API).

Puis : inspiration (B) · groupe · accompagnement · mémoire contextuelle (C).
