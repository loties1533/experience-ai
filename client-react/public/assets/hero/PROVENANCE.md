# Provenance des visuels du hero

Visuels **éditoriaux d'ambiance** — ils inspirent une envie, ils ne prouvent aucune
disponibilité, réservation, lieu ni événement réel (loi produit).

Chaque image est déclinée en 3 fichiers : `-1600.webp` (desktop), `-800.webp`
(mobile), `-1280.jpg` (repli). Toutes proviennent de plateformes à **licence
gratuite, usage commercial sans attribution** (Unsplash / Pexels). Vérifié : aucun
asset Unsplash+.

> les droits de personnes identifiables, marques ou œuvres visibles restent à confirmer
> avant tout usage promotionnel. Aucun model release n'est affirmé sans preuve.
